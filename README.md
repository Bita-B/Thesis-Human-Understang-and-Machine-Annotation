# Thesis-Human-Understanding-and-Machine-Annotation
Supplementary materials for a thesis on spatial language annotation and LLMs.

# Between Human Understanding and Machine Annotation (Thesis)
University: University of Gothenburg, Sweden
Year: 2026 

## Overview 
This repository contains supplementary materials for a thesis investigating the annotation of spatial langauge in the CUPS task setting, with a focus on spatial relation annotation and the use of vision-language models. 

The repository includes annotation prompts, human-produced annotations, and model-generated annotation results. These materials supports the documentation and analysis of the annotation process described in the thesis. 

The availability of participant data is subject to applicable consent conditions, research ethics requirements, and data-protection rules. 

## Repository Structure 
- annotation-prompts/ -Prompts used to guide the annotation process.
- human-annotations/ -Spatial relation annotations produced by the thesis author. The repository currently includes conversations 03 and 17 as examples.
- models-annotations/ -Models-generated annotation results.
- models-annotations-entities/ -Model-generated entity annotation results.

## Vision-Language Models: 
- Qwen32B, Qwen8B
- Gemma27B, Gemma4B

## Data and annotation 
The materials are organized to distinguish between human-produced annotations and model-generated outputs. This separation supports the comparison and analysis of annotation results. 
The annotation prompts document the instructions provided to the models. The annotation files document the resulting annotations for the conversations included in the repository. 

## Purpose 
This repository is intended to improve the transparency and traceability of the annotation materials associated with the thesis.
